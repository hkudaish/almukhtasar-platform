# واجهات API

جميع الاستجابات بصيغة JSON، والواجهة العامة الحالية للقراءة فقط باستثناء التحقق من اشتراك البريد.

## منفذ حاليًا

- `GET /api/articles?q=&category=&limit=` — بحث وقائمة؛ الحد الأقصى 50.
- `GET /api/articles/:slug` — تفاصيل خبر أو `404`.
- `GET /api/categories` — التصنيفات وعدد المواد.
- `GET /api/daily-brief` — موجز اليوم وحالة المراجعة.
- `POST /api/newsletter` — يتحقق من البريد ويعيد `202`؛ لا يرسل بريدًا بعد.

### إدارة تشغيلية محلية

- `GET|POST /api/admin/:resource` — قائمة وبحث وترقيم أو إضافة سجل.
- `GET|PATCH|DELETE /api/admin/:resource/:id` — عرض وتعديل وأرشفة، ويدعم `restore: true`.
- `GET|PUT /api/admin/settings` — قراءة وحفظ أقسام الإعدادات.
- `GET /api/admin/audit` — سجل التدقيق للقراءة فقط.
- `POST /api/admin/test-connection` — اختبار آمن لاتصال مصدر أو تكامل، أو تشغيل مهمة.
- `GET /api/settings/public` — الإعدادات العامة المسموح بعرضها للموقع.

الموارد المتاحة تشمل المحتوى والمصادر والتصنيفات والوسوم والمستخدمين والأدوار والمراجعات والوسائط وSEO والإعلانات والإشعارات والنشرات والتكاملات والسياسات والمهام والأرشيف والنسخ الاحتياطي.

شكل القائمة:

```json
{"data": [], "meta": {"total": 0, "available": 8, "limit": 20}}
```

## عقود المرحلة الخلفية

- المصادقة: `POST /api/v1/auth/login`، `POST /refresh`، `POST /2fa/verify`، `DELETE /account`.
- التحرير: إنشاء/تعديل المقال، إرسال للمراجعة، تحقق، اعتماد، رفض، تصحيح، وجدولة.
- المصادر: إنشاء واختبار وتعطيل، قواعد الجلب، تشغيل يدوي، وسجلات التنفيذ.
- المستخدم: حفظ ومتابعة وتفضيلات وإشعارات ومزامنة.
- الإدارة: التحليلات، الوسائط، الإعلانات، النشرات، والمنشورات الاجتماعية.

## متطلبات الحماية قبل وصل الكتابة

جلسات آمنة وCSRF، RBAC، تحديد معدل الطلبات، مخططات تحقق للمدخلات، سجل تدقيق، مفاتيح idempotency للمهام، وفحص الملفات. لا ينبغي كشف مسارات الإدارة الحالية خارجيًا قبل إضافة المصادقة.
