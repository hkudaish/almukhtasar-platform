# دليل المنتج والتجربة

## الرؤية

«المختصر» ليس مجمّع روابط؛ المنتج يحوّل الخبر إلى وحدة معرفة تتضمن ملخص 30 ثانية، سياقًا، سبب الأهمية، درجة ثقة، مصادر، وتسلسل تحديثات. المبدأ التحريري هو **الجلب الآلي ثم المراجعة والتحرير**.

## خريطة الصفحات

- عامة: الرئيسية، البحث، التصنيف، الخبر، المحفوظات.
- الثقة: من نحن، التواصل، التحرير، التصحيح، الذكاء الاصطناعي، الخصوصية، ملفات الارتباط، الشروط، حقوق النشر.
- الإدارة: المتابعة، المحتوى، المصادر، الأتمتة، المراجعات، المستخدمون، التحليلات، الإعدادات.
- لاحقًا بعد المصادقة: تسجيل الدخول، ملف المستخدم، التفضيلات، الإشعارات، النشرات، متابعة قصة.

## رحلات المستخدم

1. قارئ سريع: الرئيسية ← مختصر اليوم ← الاستماع/المشاركة.
2. قارئ متعمق: بطاقة الخبر ← ملخص 30 ثانية ← السياق ← المصادر والتسلسل.
3. بحث واسترجاع: البحث ← كلمة أو تصنيف ← نتيجة ← حفظ محلي.
4. محرر: مادة مستوردة ← معالجة ← مسودة ← مراجعة/تحقق ← اعتماد ← جدولة/نشر.
5. مسؤول مصادر: إضافة مصدر ← اختبار ← قواعد وتصنيف ← موافقة ← مراقبة التشغيل.

## نظام التصميم

- اتجاه RTL افتراضي، وبنية جاهزة لإضافة LTR على مستوى `html`.
- اللون الأساسي `#e83d4f` للقرارات والهوية، والكحلي للثقة، والأخضر لحالة التحقق.
- شبكة قصوى 1180px، بطاقات نصف قطرها 18–28px، ومسافات تعتمد مضاعفات 4px.
- حالات تركيز ظاهرة، رابط تخطٍ للمحتوى، نصوص بديلة دلالية، وتباين للوضعين.
- الاستجابة: ثلاث أعمدة للحاسب، عمودان للجهاز اللوحي، وعمود واحد للجوال.

## حدود النسخة الحالية

واجهة الإدارة تحاكي الإجراءات وتوضح حالات النظام لكنها لا تكتب إلى قاعدة بيانات. لا توجد مزاعم بأن البيانات أخبار حية؛ كل المحتوى موسوم في التذييل كبيانات نموذجية. هذا الفصل مقصود حتى تكتمل المصادقة والخدمات الخلفية قبل السماح بالنشر.
