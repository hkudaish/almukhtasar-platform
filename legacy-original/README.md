# منصة المختصر

نسخة تشغيلية عربية لمنصة أخبار ذكية مبنية بـ Next.js وTypeScript. تنفذ المرحلة الأساسية من تجربة القارئ ولوحة التحرير، وتضع عقود API ومخطط PostgreSQL للمرحلة الخلفية.

## ما يعمل الآن

- صفحة رئيسية RTL متجاوبة، وضع داكن، أقسام وتصنيفات وموضوعات رائجة.
- بحث وتصفية، حفظ محلي، مشاركة، قراءة صوتية عبر المتصفح، وتكبير نص الخبر.
- صفحات خبر وتصنيف وسياسات مؤسسية وخصوصية وتصحيح وذكاء اصطناعي.
- لوحة إدارة متعددة المساحات للمحتوى والمصادر والجدولة والمراجعات والمستخدمين والتحليلات والإعدادات.
- قاعدة SQLite تشغيلية للوحة الإدارة، مع CRUD دائم، أرشفة واستعادة، إعدادات، نسخ احتياطي، واختبارات اتصال وسجل تدقيق.
- API تجريبية للقراءة والبحث والتصنيفات ومختصر اليوم والتحقق من اشتراك البريد.
- Sitemap وrobots وWeb App Manifest وMetadata للصفحات.
- مخطط Prisma واسع يدعم الإصدارات والصلاحيات وسير التحرير والتحقق والتحليلات.

> بيانات الموقع العامة نموذجية داخل `lib/data.ts`. بيانات الإدارة دائمة محليًا داخل `data/almukhtasar-admin.db`. يتطلب الإنتاج نقلها إلى PostgreSQL وإضافة مزود مصادقة قبل تعريض لوحة الإدارة للإنترنت.

## التشغيل

```bash
npm install
copy .env.example .env
npm run dev
```

افتح `http://localhost:3000`، ولوحة الإدارة في `http://localhost:3000/admin`.

تتطلب قاعدة الإدارة المحلية Node.js 22.5 أو أحدث لاستخدام `node:sqlite`. تُنشأ القاعدة والبيانات الأولية تلقائيًا عند أول تشغيل.

## التحقق

```bash
npx tsc --noEmit
npm run build
```
